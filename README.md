# firefly-bulb

Interpreter for running [Bulb Script](https://docs.fireflyzero.com/dev/bulb/) games on [Firefly Zero](https://fireflyzero.com/).

If you want to write your own interpreter for Bulb, the core logic of this project lives in the [bulb-parser](https://github.com/firefly-zero/bulb-parser) repo, which has Firefly-independent no-std parser and interpreter for the script.

See [Bulb Script documentation](https://docs.fireflyzero.com/dev/bulb/) for getting started and more info on the script.
